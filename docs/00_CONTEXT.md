## 3. Ключова логіка роботи з вправою

**Важливо**: користувач може виконувати вправи двома шляхами.

1. Користувач обирає режим: **PDF** (друк) або **В додатку** (введення з клавіатури).
2. Перед початком показується коротке правило (в акордеоні можна розкрити повне).
3. У режимі PDF: генерується документ, користувач пише від руки, а потім повертається в додаток, щоб внести результати.
4. У режимі додатку: користувач одразу бачить речення та інпути для введення перекладу.
5. **Пропущені слова:** якщо користувач не знає слово, він може ввести `...`. AI розпізнає це, і додає оригінальне слово в список для подальшого вивчення (Flashcards/Quizlet).
6. Кнопка «Перевірити»: AI аналізує відповіді, знаходить помилки.
7. Дві оцінки: засвоєння теми + загальна граматика.
8. Якщо є помилки по темі → кнопка «Робота над помилками».
9. Якщо є помилки по загальній граматиці (включно з орфографією) → список слів показується користувачу для редагування, після чого зберігається у форматі Quizlet та/або Flashcards.
10. **Error recycling:** при генерації нової вправи AI включає 3–5 минулих помилок і Quizlet-слів.

## 3. Ключова логіка роботи з вправою

**Важливо**: перед початком вправи користувач бачить коротке правило (з можливістю розгорнути повне в акордеоні).
Далі користувач обирає один із двох режимів: **Роздрукувати PDF** або **Виконати в додатку**.

### Режим PDF (для тих, хто друкує):

1. Генерується PDF з реченнями для перекладу.
2. Користувач друкує, пише переклади від руки.
3. У застосунку: відображається речення + еталонна відповідь AI (тільки для читання).
4. Поле «Ваша відповідь»:
   - Якщо помилки не було → чекбокс → поле блокується.
   - Якщо помилка була → редагує поле, вписуючи свій неправильний варіант.
5. Кнопка «Перевірити»:
   - Неред. поле + чекбокс = помилок немає.
   - Редаговане поле = AI розбирає помилку користувача.

### Режим у додатку (без друку):

1. Відображаються речення та порожні інпути для введення перекладу.
2. Якщо користувач не знає слово, він ставить троєкрапку `...`.
3. Після заповнення всіх полів — кнопка «Перевірити». AI оцінює відповіді (як і в режимі PDF).
4. AI автоматично розпізнає `...` і додає оригінальне слово до списку для вивчення.

### Оцінювання та розбір помилок (для обох режимів):

6. Дві оцінки: засвоєння теми + загальна граматика.
7. Якщо є помилки по темі → кнопка «Робота над помилками».
8. Якщо є помилки по загальній граматиці або орфографії → формується список слів.
   - Користувач **бачить цей список** перед експортом і може видалити зайве.
   - Після підтвердження → експорт у Quizlet та/або генерація вправи на написання (Spelling).
9. **Error recycling:** при генерації нової вправи AI включає 3–5 минулих помилок і Quizlet-слів.
   - Кожна помилка має `timesRecycled`, `successCount`, `failureCount`, `status`.
   - 3 правильних відповіді → `ARCHIVED_SUCCESS` (вийшла з пулу).
   - 5 неправильних → `ARCHIVED_STUCK` (показуємо банер «спец. завдання»).
   - Пріоритет у пулі: STUCK → свіжі невдачі → звичайні.

## 4. Структура навчального плану

Рівень → Теми → Підтеми → Шаблони

Приклад:

- B1 → Modal Verbs → Obligation (must, have to, should), Permission (can, could, may, might), Prohibition (mustn't, don't have to)
- Кожен день — одна підтема.
- Коли всі підтеми пройдені → день на «перемішку».

## 9. Рівні CEFR

A1 → A2 → A2+ → B1 → B1+ → B2 → C1 → C2

**У коді:** `A1`, `A2`, `A2_PLUS`, `B1`, `B1_PLUS`, `B2`, `C1`, `C2`.
**UI показує:** `A1`, `A2`, `A2+`, `B1`, `B1+`, `B2`, `C1`, `C2` (через `CEFR_LEVEL_LABELS`).

Кожен рівень має:

- `slots_<level>.json` — дієслівні слоти
- `slots_nouns_<level>.json` — не-дієслівні слоти
- `templates_<level>.json` — граматичні шаблони

Для рівня B1 файл шаблонів історично називається `templates_b1_advanced.json`.

---

## 10. Формат шаблонів і слотів

Кожен шаблон містить:

- `id` — унікальний ідентифікатор
- `pattern` — граматична структура
- `generation_hint` — інструкція для AI
- `slots` — посилання на слоти (`$ref`)
- `examples` — 2-3 приклади

Кожен слот містить рівні: `basic`, `intermediate`, `advanced`.

Посилання: `slots_b1#/slots/present_simple/affirmative/V1`

---

## 11. Redis — ключі та структури

- `ai:<hash>` — кэш відповідей AI (TTL 24 год)
- `ratelimit:<userId>:<minute>` — лічильник запитів (TTL 60 сек)
- `session:<sessionId>` — сесія NextAuth (TTL 30 днів)
- `bull:pdf:*` — черга PDF
- `bull:email:*` — черга email

## 13. Принципи розробки

- **Ітеративність**: MVP → розширення.
- **Human-in-the-loop**: користувач не править еталон AI, а вводить свою відповідь.
- **Cross-check**: дві моделі перевіряють одна одну.
- **Гібрид**: шаблони гарантують граматику, AI — варіативність.
- **Безкоштовні ресурси**: мінімум платних залежностей.
- **Адаптивні пороги**: константи (3/5) у `packages/shared/constants`, не в коді.
