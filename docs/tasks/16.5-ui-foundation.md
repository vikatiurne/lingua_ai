## 🧠 Алгоритм (словами)

### Встановлення

```bash
cd apps/web
pnpm add clsx tailwind-merge class-variance-authority lucide-react tailwindcss-animate next-themes
pnpm add @radix-ui/react-label @radix-ui/react-slot
pnpm dlx shadcn@latest init
# TypeScript: yes, Style: New York, Base color: Slate, CSS variables: yes
pnpm dlx shadcn@latest add button input label card
```

**Якщо `shadcn init` падає** — створити `components.json`, `lib/utils.ts`, оновити `globals.css` і `tailwind.config.ts` вручну (див. код нижче). Компоненти з `components/ui/*` скопіювати з docs.shadcn.com.

### `globals.css` і `tailwind.config.ts`

Генеруються `shadcn init`. **Не писати вручну.** Після init перевірити:
- `globals.css` містить `:root { --background: ...; --foreground: ...; ... }` і `.dark { ... }`
- `tailwind.config.ts` має `darkMode: ["class"]`, `extend.colors` з CSS-змінними, `plugins: [require("tailwindcss-animate")]`

### Дизайн login/register

Форми переписуються з голих `<input>` на:
- `<Card>` — обгортка (у `(auth)/layout.tsx`)
- `<Label htmlFor>` + `<Input id>` — поля
- `<Button type="submit">` — кнопка
- Помилки — `<p className="text-sm text-destructive">`
- Root-помилки (невірний пароль, 429) — банер над формою
- Кнопка disabled під час `formState.isSubmitting`, текст «Вхід...» / «Увійти»

**Логіка форм не змінюється** — `useForm`, `zodResolver`, `signIn`, `router.push` залишаються як у задачі 16.


### `lib/utils.ts`

```ts
import { clsx, type ClassValue } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

### `components/theme-provider.tsx`

```tsx
"use client";

import { ThemeProvider as NextThemesProvider } from "next-themes";
import type { ComponentProps } from "react";

export function ThemeProvider({
  children,
  ...props
}: ComponentProps<typeof NextThemesProvider>) {
  return <NextThemesProvider {...props}>{children}</NextThemesProvider>;
}
```

### `components/theme-toggle.tsx` — **mounted trick обов'язковий**

```tsx
"use client";

import { Moon, Sun } from "lucide-react";
import { useTheme } from "next-themes";
import { useEffect, useState } from "react";

import { Button } from "@/components/ui/button";

export function ThemeToggle() {
  const { theme, setTheme } = useTheme();
  const [mounted, setMounted] = useState(false);

  useEffect(() => {
    setMounted(true);
  }, []);

  // Не рендерити тему до hydration, інакше mismatch
  if (!mounted) {
    return (
      <Button variant="ghost" size="icon" aria-label="Toggle theme" disabled>
        <Sun className="h-5 w-5" />
      </Button>
    );
  }

  return (
    <Button
      variant="ghost"
      size="icon"
      aria-label="Toggle theme"
      onClick={() => setTheme(theme === "dark" ? "light" : "dark")}
    >
      {theme === "dark" ? (
        <Sun className="h-5 w-5" />
      ) : (
        <Moon className="h-5 w-5" />
      )}
    </Button>
  );
}
```

### `app/layout.tsx` — **`suppressHydrationWarning` критичний**

```tsx
import { Inter } from "next/font/google";
import { ThemeProvider } from "@/components/theme-provider";
import "./globals.css";

const inter = Inter({ subsets: ["latin", "cyrillic"] });

export const metadata = {
  title: "Lingua AI",
  description: "Персональна платформа для вивчення англійської мови з AI",
};

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="uk" suppressHydrationWarning>
      <body className={inter.className}>
        <ThemeProvider
          attribute="class"
          defaultTheme="system"
          enableSystem
          disableTransitionOnChange
        >
          {children}
        </ThemeProvider>
      </body>
    </html>
  );
}
```

**Чому `suppressHydrationWarning`:** `next-themes` додає `class="dark"` до `<html>` через inline script **до** hydration. Без цього Next.js видасть помилку hydration mismatch.

## ⚠️ Що може піти не так

| Проблема | Рішення |
|---|---|
| `shadcn init` падає | Створити `components.json` і `lib/utils.ts` вручну; скопіювати `globals.css`/`tailwind.config.ts` з docs.shadcn.com |
| Hydration mismatch | Перевірити `suppressHydrationWarning` на `<html>` |
| Theme flash при завантаженні | Перевірити `ThemeProvider` у `layout.tsx`; `disableTransitionOnChange` |
| Кольори не застосовуються | Перевірити `globals.css` → `:root { --background: ... }` і `tailwind.config.ts` → `colors.background: "hsl(var(--background))"` |
| Inter без кирилиці | Перевірити `subsets: ["latin", "cyrillic"]` |
| Favicon не оновлюється | Очистити кеш браузера, перезапустити dev |
| `next-themes` не працює в Server Component | `ThemeToggle` — `"use client"`; `ThemeProvider` — `"use client"` |
| `ThemeToggle` не працює до hydration | Це очікувано; disabled до `mounted` — правильна поведінка |
