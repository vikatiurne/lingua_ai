## 🔧 Хрупкі місця (обов'язково)

### 1. Очищення тексту
Перед відправкою в TTS, бажано прибрати зайві символи (наприклад, `...`), щоб браузер не читав їх вголос як "dot dot dot".

### 2. Сумісність
Web Speech API чудово працює в Chrome, Edge, Safari. У Firefox можуть бути обмеження. Тому важливо, щоб кнопка просто не з'являлася, якщо API недоступне, замість того, щоб видавати помилку.
