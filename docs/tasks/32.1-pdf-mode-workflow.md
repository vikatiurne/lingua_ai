## 🎯 Мета

Реалізувати повний цикл режиму друку (PDF):

1. Генерація вправи + автоматичне завантаження PDF-файлу.
2. Друк та заповнення аркуша від руки (з таймером на друк).
3. Перевірка результатів на спеціальній сторінці та відправлення на оцінку AI.

## 🔧 Хрупкі місця

### 1. Немає `mode` у БД
Колонки `mode` (app/pdf) в `Exercise` немає. Незавершена PDF-вправа, відкрита з історії («Продовжити»), показує app-форму. Виправлення потребує Prisma-міграції — окрема задача.

### 2. `field-sizing: content`
Авто-висота Textarea — чистий CSS (Chrome/Firefox/Safari 17.4+, 2024+). У старих браузерах поле зафіксованої висоти.

### 3. Залежність від AI-промпта для `...`
`errorType: "skipped"` та `vocabularyToAdd` для пропущених слів визначає AI за промптом `evaluate-answers.ts`; код лише зберігає `...` цілком (`normalizeForPrompt`). Зміна промпта може зламати потік.

### 4. Роут `/exercise/pdf`
Статичний роут перекриває `[id]`. Якщо колись зʼявиться вправа з id `"pdf"` — буде конфлікт (практично неможливо, ULID).
