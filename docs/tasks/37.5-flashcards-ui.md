## 🔧 Хрупкі місця (обов'язково)

### 1. 3D Анімація
Використано чистий CSS + Tailwind-утиліти в `globals.css`:
```css
.perspective-1000 { perspective: 1000px; }
.transform-style-3d { transform-style: preserve-3d; }
.rotate-y-180 { transform: rotateY(180deg); }
.backface-hidden {
  backface-visibility: hidden;
  -webkit-backface-visibility: hidden;
}
```
Обидві сторони картки абсолютно позиціоновані всередині контейнера з фіксованою висотою (`h-64`), інакше при перевороті картка «стрибає».

### 2. Озвучка
`window.speechSynthesis` перевіряється на `typeof window === "undefined"`, щоб не падати під час SSR. Клік по кнопці озвучки має `stopPropagation()`, інакше він одночасно перевертає картку.

### 3. Стан сесії
`queue` — це `useState`-копія вхідного масиву:
- «Знаю» робить `slice(1)`;
- «Не знаю» переносить перший елемент у кінець;
- після перезавантаження сторінки сесія починається заново (прогрес у БД не зберігається).

### 4. Дані для карток
Картки показуються лише для слів, які користувач явно зберіг у Задачі 37. `distinct: ["word"]` прибирає дублікати з різних вправ. Видалені слова (`isDeleted: true`) і неактивні помилки не потрапляють у сесію.

### 5. Без міграцій
Схема БД не змінювалася: використано наявні поля `isSavedToTraining`, `isDeleted`, `status`, `word`, `translation`.
