## 🧠 Алгоритм (словами)

### 1. Навігація
- Додати посилання в Sidebar та Dashboard (як звичайні `<Link>`).

### 2. `app/(dashboard)/library/page.tsx` (Server Component)
1. `user = await requireUser()`.
2. Отримати `searchParams` (`?level=B1`).
3. Визначити `selectedLevel = searchParams.level || user.level || "A1"`.
4. `templateFile = await loadTemplateFile(selectedLevel)`.
5. Рендер: `<LevelSelector current={selectedLevel} />` та `<TopicList topics={templateFile.topics} level={selectedLevel} />`.

### 3. `components/library/level-selector.tsx` (Client)
- Кнопки/таби для всіх `CEFR_LEVELS`.
- При кліку: `router.push(\`/library?level=\${level}\`)`.
- Підсвічувати активний рівень.

### 4. `components/library/topic-list.tsx`
- Використати `Accordion` з shadcn.
- Кожен `AccordionItem` — тема.
- Всередині — список підтем.
- Біля кожної підтеми — `<Button size="sm" variant="outline">Тренувати</Button>`.
- `onClick` → `router.push("/exercise")` (тимчасова заглушка).

## ⚠️ Нюанси

- **`user.level`** може бути `null`. Тоді показуємо A1.
- **`loadTemplateFile`** повертає `topics[].topic` та `topics[].subtopics[].name`. Типи вже є.
- **UI:** Використовуйте кольори нашої нової теми (`bg-background`, `text-primary` тощо). Ніяких хардкодів.
- **Кнопка "Тренувати"** на цьому етапі нікуди не веде (404), і це нормально. Головне — відпрацювати навігацію по бібліотеці.
