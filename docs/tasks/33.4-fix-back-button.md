## 🎯 Мета
Заборонити повторне проходження вже оціненої вправи (статус `evaluated`) та виправити навігацію.

## ✅ Acceptance Criteria

### 1. Клієнтська навігація (Заміна push на replace)
- [ ] У компонентах, де відбувається редірект на сторінку результатів після успішної оцінки (у `components/exercise/exercise-form.tsx` та `components/exercise/pdf-check-form.tsx`), замінити `router.push('/exercise/[id]/result')` на `router.replace('/exercise/[id]/result')`.
- [ ] Це видалить сторінку форми з історії браузера, тому кнопка "Назад" вестиме на сторінку до початку вправи (наприклад, на `/plan`).

### 2. Серверний захист (Сторінка вправи)
- [ ] У файлі `app/(dashboard)/exercise/[id]/page.tsx` додати перевірку статусу:
  ```ts
  if (exercise.status === 'evaluated') {
    redirect(`/exercise/${exercise.id}/result`);
  }
