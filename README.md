## 💡 Навіщо це

Існуючі застосунки для вивчення мов (Duolingo, LingQ, Anki) добре дають контент, але погано розуміють **конкретного учня**. Ти ходиш по темах, які вже знаєш, або пропускаєш те, де реально є пробіли.

**Lingua AI** вирішує це так:

1. **Тестує твій рівень** — адаптивно, за темами.
2. **Будує персональний план** — обирає теми, де є пробіли, і дає їх у правильному порядку.
3. **Генерує щоденні вправи** — на переклад (укр ↔ англ) з активною лексикою теми.
4. **Перевіряє роботу** — за двома критеріями: засвоєння теми + загальна граматика.
5. **Пояснює помилки** — українською, з прикладами.
6. **Рекомендує матеріали** — подкасти, фільми, статті за темою.

## 🎯 Як це працює для учня

**Ранок.** Відкриваєш застосунок — бачиш завдання на сьогодні: тема «Present Perfect» (підтема «for/since»).

**Перед вправою.** AI дає коротке пояснення теми українською.

**Друк.** Обираєш кількість речень (укр → англ і англ → укр), натискаєш «Створити PDF». Роздруковуєш аркуш — кожне речення з місцем для рукописного перекладу.

**Робота руками.** Пишеш переклади олівцем. Це важливо — рука запам'ятовує більше, ніж клавіатура.

**Перевірка.** Повертаєшся в застосунок. Бачиш ті самі речення + еталонні відповіді від AI.
- Де не помилився — ставиш галочку.
- Де помилився — вписуєш свій варіант (той, що написав на аркуші).

**Оцінка.** AI аналізує твої помилки, ставить дві оцінки:
- **Засвоєння теми** — наскільки добре ти розібрався саме в цій граматиці.
- **Загальна граматика** — артиклі, прийменники, порядок слів тощо.

**Розбір.** Отримуєш список помилок з поясненнями українською. Помилки по темі → пропонує «Роботу над помилками». Помилки по загальній граматиці → можна експортувати у Quizlet.

**Закріплення.** AI рекомендує подкасти, фільми, статті, де ця тема активно використовується.

**Нагадування.** Можна додати в календар «Час вчитися» — на зручний час.

## 🧠 Як це працює під капотом

Ключова ідея — **гібрид шаблонів і AI**:

- **Шаблони** гарантують граматичну правильність. У нас 24 JSON-файли з граматичними шаблонами для всіх рівнів CEFR. Кожен шаблон — це структура речення + слоти для заповнення.
- **AI** заповнює слоти лексикою, перевіряє відповіді учня і пояснює помилки.
- **Cross-check** — для критичних завдань (генерація еталонів, оцінка) використовуються дві різні моделі. Якщо вони розходяться — результат позначається «потребує перевірки».

Такий підхід дає:
- **Гарантовану граматику** — AI не може вигадати неправильну структуру, бо вона задана в шаблоні.
- **Живу лексику** — AI підставляє природні слова й фрази.
- **Дешевизну** — шаблони зменшують кількість запитів до AI на 60–80%.

## 🛠️ Технології

**Frontend + Backend**
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- React Flow (візуалізація плану)

**Дані**
- PostgreSQL 16 (Docker)
- Prisma ORM
- Strapi 5 — CMS для тем і шаблонів
- Redis 7 — кеш і черги

**AI**
- OpenRouter (основний)
- Google Gemini Flash (fallback)
- DeepSeek (fallback)
- Cross-check між двома моделями

**Інше**
- PDF: `pdf-lib` / `pdfmake`
- Календар: генерація `.ics`
- Аутентифікація: NextAuth.js
- Монорепо: pnpm workspaces + Turborepo
- Docker Compose

## 🚀 Як запустити локально

**Вимоги:** Node.js 22+, pnpm 9+, Docker.

```bash
# 1. Клонувати репозиторій
git clone <repo-url> lingua-ai
cd lingua-ai

# 2. Встановити залежності
pnpm install

# 3. Налаштувати середовище
cp .env.example .env
# Заповнити NEXTAUTH_SECRET, OPENROUTER_API_KEY, GEMINI_API_KEY, DEEPSEEK_API_KEY

# 4. Підняти інфраструктуру (Postgres + Redis + Strapi)
docker compose up -d

# 5. Застосувати міграції Prisma
pnpm --filter web db:migrate

# 6. Засіяти Strapi даними (8 рівнів + теми + підтеми)
pnpm seed

# 7. Запустити Next.js
pnpm dev:web
```

Застосунок буде доступний на [http://localhost:3001](http://localhost:3001).
Strapi Admin — на [http://localhost:1337/admin](http://localhost:1338/admin).
