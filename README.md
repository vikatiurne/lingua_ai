# AI English Learning Platform

Персонализированная платформа для изучения английского языка с использованием ИИ. 
Уровни A1–C2. Оценка уровня, генерация учебного плана, ежедневные упражнения, 
разбор ошибок, экспорт в Quizlet, календарь напоминаний.

## Ключевая идея

ИИ-платформа выступает в роли методиста, генератора контента и экзаменатора.
Ученик проходит тестирование → получает уровень → получает план → ежедневно
выполняет упражнения на перевод → ИИ оценивает → разбирает ошибки → рекомендует материалы.

## Стек

- **Frontend + Backend**: Next.js 14 (App Router) + TypeScript
- **БД**: PostgreSQL (Docker) + Prisma ORM
- **UI**: Tailwind CSS + shadcn/ui
- **Визуализация плана**: React Flow
- **AI**: OpenRouter / Gemini Flash / DeepSeek (бесплатные модели с fallback)
- **PDF**: pdf-lib или pdfmake
- **Календарь**: генерация .ics + опционально Google Calendar API
- **Аутентификация**: NextAuth.js (email + OAuth)
- **Кэш и очереди**: Redis + BullMQ

## Что уже готово

24 JSON-файла со слотами и шаблонами для всех уровней CEFR:
- `slots_<level>.json` — глагольные слоты
- `slots_nouns_<level>.json` — не-глагольные слоты
- `templates_<level>.json` — грамматические шаблоны

Уровни: A1, A2, A2+, B1, B1+, B2, C1, C2.

## Ключевые пользовательские сценарии

1. Регистрация и тестирование уровня
2. Просмотр персонального плана (React Flow)
3. Ежедневное задание: объяснение → генерация PDF → ручной перевод → 
   ввод ошибок → оценка ИИ → разбор → рекомендации
4. Работа над ошибками: Quizlet-экспорт, повторное упражнение
5. Календарь: напоминание "Час вчитися"

## Принципы разработки

- **Итеративность**: MVP → расширение
- **Human-in-the-loop**: пользователь не правит эталон ИИ, а вводит свой ответ
- **Cross-check**: две модели проверяют друг друга
- **Гибрид**: шаблоны гарантируют грамматику, ИИ — вариативность
- **Бесплатные ресурсы**: минимум платных зависимостей
